# NPS Monitor

Локальный интерактивный дашборд для Excel-файлов формата `Мониторинг NPS`.

## Запуск

Из папки проекта выполните:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Образец из папки `Исходные данные` загрузится автоматически. Другой файл того же формата можно выбрать в левой панели. Кнопка `Сохранить как PNG` создаёт изображение отчёта для пересылки.



## Деплой на Vercel

1. Залейте проект на GitHub.
2. Перейдите на `https://vercel.com` и нажмите **New Project**.
3. Импортируйте репозиторий и выберите корневую папку проекта.
4. Build Command оставьте пустым.
5. Output Directory оставьте пустым.
6. Запустите деплой.

Файл `vercel.json` уже добавлен, чтобы явным образом определить статический сайт.
